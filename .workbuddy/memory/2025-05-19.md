### 第一轮：问题分析与修复（10项）
1. **CRITICAL: API Key 硬编码** - `config.yaml` 替换为 `YOUR_API_KEY_HERE`
2. **CRITICAL: GitTool Shell 注入** - `git_tool.py` 引入 `shlex.quote` / PowerShell 单引号转义
3. **CRITICAL: 文件工具路径遍历** - `file_tools.py` 新增 `_resolve_and_validate_path()`
4. **MEDIUM: _encoder_cache 类变量问题** - `agent.py` 移除 cleanup 中的 clear()
5. **MEDIUM: format_llm_error lru_cache** - 移除 `lru_cache(maxsize=1)` 装饰器
6. **MEDIUM: ConfigValidator 范围不匹配** - max_concurrent_tools 1-10→1-30
7. **MEDIUM: Logger 类级可变状态** - 移除类级 `_write_queue`/`_writer_task` 默认值

9. **LOW: PIL.LANCZOS 废弃** - 改用 `Image.Resampling.LANCZOS`

### 第二轮：全面优化（9项）
1. **API Key 环境变量** - `config.py` 支持 `MINIMAX_API_KEY` 环境变量（优先），`MINI_AGENT_API_KEY` 作为兼容别名
2. **ConfigValidator 接入** - `Config.from_yaml()` 加载后自动调用 `validate_or_raise()`
3. **MessageValidator 接入** - `LLMClient.generate()` 前置消息结构校验
4. **统一 Git 操作** - 创建 `batch_shared.py`，提取 `get_git_status_sync()` 和 `get_tree_sync()` 共享函数，消除3处重复实现
5. **MultiBash 安全加固** - `batch_tools.py` 的 `MultiBashTool.execute()` 前置 `assess_command_danger` 检查，阻止 BLOCKED 级别命令
6. **Note Tool 限长** - `note_tool.py` 添加 `MAX_NOTE_CONTENT_LENGTH = 10000`
7. **假测试修复** - `test_agent.py`、`test_llm.py`、`test_llm_clients.py`、`test_integration.py` 中 `return True/False` 替换为 `assert`，添加 `@pytest.mark.integration`
8. **测试补全** - 新增 `conftest.py`、`test_command_validator.py`、`test_error_handler.py`、`test_batch_shared.py`、`test_config_validator.py`
9. **根目录清理** - `test_box.py`、`fetch_m27.py`、`fetch_news.py`、`fix_logo.py` 移至 `scripts/`
10. **类型注解补全** - `agent.py` 的 `execute_single_tool`、`execute_tools_sequential`、`execute_tools_parallel` 添加完整类型注解
